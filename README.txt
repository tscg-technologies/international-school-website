--------------------------------------------------------------------------------
1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This is a modern, premium-quality, professional, and fully responsive 
demonstration website created for portfolio and presentation purposes. It illustrates 
a contemporary Indian international school offering holistic educational pathways, 
world-class smart campus facilities, innovative pedagogy, vibrant campus life, 
and a parent-friendly admissions journey.

MANDATORY DISCLAIMER:
This website is an illustrative educational prototype and portfolio demonstration. 
All school names, branding, academic curricula, statistics, addresses, contact 
numbers, staff profiles, and testimonials are entirely fictional. No actual 
enrolments or fees are collected, and no affiliation with any real school, 
education board, or governing authority is claimed or implied.

3. HOW TO RUN THE WEBSITE
--------------------------------------------------------------------------------
No web server, node package installations, build steps, or compilation are required.
1. Simply double-click `index.html` or drag and drop it into any modern web 
   browser (Chrome, Edge, Firefox, Safari).
2. The website will immediately load and display with complete styling, animations, 
   and interactive features.

5. REPLACING PLACEHOLDER IMAGES WITH CUSTOM AI IMAGES
--------------------------------------------------------------------------------
To replace the generated visual placeholders with your own AI-generated images:
1. Generate your AI images in `.webp` format (recommended resolution: 800x600 or 1200x800).
2. Save them using the exact filenames in `assets/images/`:
   • hero-school.webp
   • school-campus.webp
   • classroom.webp
   • students-learning.webp
   • science-lab.webp
   • computer-lab.webp
   • school-library.webp
   • sports-facility.webp
   • arts-activities.webp
   • school-events.webp
   • admissions.webp
   • teacher-classroom.webp
   • gallery-01.webp
   • gallery-02.webp
   • gallery-03.webp
   • gallery-04.webp
   • gallery-05.webp
   • gallery-06.webp
3. Refresh `index.html` in your browser. The new images will immediately display!
4. If an image is missing or cannot load, the website's built-in intelligent SVG fallback
   automatically renders an attractive educational placeholder, preventing any broken links.
